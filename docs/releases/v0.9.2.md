Fetchrail 0.9.2 makes browser download capture work consistently across sites and keeps browser-generated files in the browser.

## Browser download capture

- **HTTP and HTTPS downloads:** The same verified handoff applies across sites. Captured transfers use browser session details only if you enable **Use browser session for captured files** and grant the relevant site access.
- **Browser-generated files:** `blob:` and `data:` downloads finish in the browser. Fetchrail no longer tries to replace them with a separate network request inferred from the filename or timing.
- **Browser fallback:** Downloads the companion cannot safely take over stay in the browser. Older paused browser-owned downloads can recover without starting a second transfer.

## Compatibility and limitations

This release covers Windows x64 and Linux x64/ARM64 desktop builds and the browser companion source. Real-browser fixtures verified Chromium regular and Firefox regular, private, and isolated container transfers byte-for-byte. Chromium private mode is not covered by that qualification. The Chrome Web Store update is deferred for this release; other store review and rollout are independent of the desktop release. The Android developer preview is unchanged.
