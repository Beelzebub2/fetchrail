Fetchrail 0.8.5 carries forward the browser companion improvements from the unreleased v0.8.3 and v0.8.4 tags, with updated release qualification checks for browser-verified downloads.

## Browser companion

- Improve capture reliability and independent handling of concurrent browser downloads in Chromium and Firefox.
- Preserve the browser's filename, private-session context and safe fallback behavior while transfers are verified and accepted by the desktop app.
- Allow the native engine to consume a verified full GET without issuing a second request or depending on optional byte-range support.

## Release qualification

- Verify the actual single-connection response used by authenticated browser handoffs, including confirmation that its exact bytes are consumed once.
- Update embedded Chromium and Firefox integration fixtures to exercise current extension manifest, permissions, native message framing and download lifecycle behavior.
- Verify that a successful full GET remains usable even when a server's range responses are malformed; ordinary parallel downloads still reject invalid Content-Range responses.

The earlier release tags remain immutable for traceability. Chrome Web Store submission follows the signed desktop release checks; Google controls review and rollout.
