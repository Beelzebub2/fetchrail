## What changed

- **Authenticated downloads:** Download using a selected signed-in browser window, including private windows, from the desktop app or browser companion.
- **Download reliability:** Recover interrupted browser handoffs without duplicate transfers, keep credentials isolated, and preserve future download schedules.
- **Settings and recovery:** Save settings consistently, protect saved credentials, retry blocked file removal, and restore downloads after a failed power action.
- **Torrents and queues:** Prevent scheduling and file-selection races, preserve rapid selection changes, and improve import cancellation and restart recovery.
- **Interface:** See combined transfer speed in one place, manage large file-category lists more easily, and adjust interface size for larger screens. Dialogs work more reliably with the keyboard.
- **Browser companion and diagnostics:** Defer extension updates during active captures, reject ambiguous request matches, recover failed status polling, and improve localized diagnostics and installation guidance.
