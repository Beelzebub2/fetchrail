Fetchrail 0.8.4 carries forward the browser companion improvements prepared for v0.8.3 and repairs the Linux release qualification test that prevented those changes from reaching the Chrome Web Store.

## Browser companion

- Make concurrent browser downloads independent while preserving each file's name, request context and retryable state.
- Improve Chromium and Firefox capture recovery, cancellation, status feedback and native confirmation of accepted downloads.
- Keep the browser in control when a handoff cannot be verified or completed.

## Release qualification

- Align the Linux and Windows browser-session integration checks with the engine's single-connection, retained full-GET verification path. Ordinary HTTP range downloads continue to require the configured parallel connections.
- Assert that captured browser downloads consume their verified response without fetching the file again, while still checking exact SHA-256 output.

The original v0.8.3 tag was retained for traceability. Chrome Web Store submission follows successful signed desktop build and qualification; store review and rollout remain under Google's control.
