Choose a package for your distribution

  • Ubuntu, Mint, Kali and Debian: choose a matching deb package. Install with sudo apt install ./Fetchrail-vVERSION-linux-x64.deb, substituting the downloaded filename.
  • Fedora: choose rpm and use sudo dnf install ./Fetchrail-vVERSION-linux-x64.rpm, substituting the downloaded filename.
  • Other glibc desktops: use an AppImage or native archive. Native archives require compatible GTK3 and WebKitGTK 4.1 libraries.
  • Arch: the release's release-metadata.tar.gz includes a binary PKGBUILD recipe. Inspect it before running makepkg -si.

Run uname -m: x86_64 means x64; aarch64 means ARM64. Browser CPU detection is unreliable. Release glibc artifacts are not certified for musl/Alpine or older WebKitGTK systems. Check the Linux guide and tested distro and CPU combinations before installing.

AppImage installation and updates

Keep the AppImage in a persistent, writable location. Make it executable with chmod +x Fetchrail-vVERSION-linux-x64.AppImage, using your filename. The Linux guide covers FUSE requirements and the alternative extracted launch. Writable AppImages support signed automatic updates; native packages update through their package manager, while archives and extracted AppImages update manually.

Connect your browser

Launch Fetchrail once to register its native host, then follow the browser integration guide. Browser package sandboxing can affect native messaging; see the Linux guide for custom profiles and sandbox limits.
