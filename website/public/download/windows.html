Download Fetchrail for Windows

A free Windows download manager for HTTP and HTTPS files. Use up to 32 connections, pause and resume supported transfers, and organize downloads with queues, schedules and speed limits.

Install for your Windows account

  1. Download the Windows x64 setup from the latest release. Windows ARM64 does not have a native setup package in this release.
  2. Run setup. It installs in your account at %LOCALAPPDATA%\Programs\Fetchrail without an administrator prompt.
  3. Ensure the Microsoft Edge WebView2 Runtime is installed, then launch Fetchrail.
  4. Paste an HTTP or HTTPS file link, choose a destination and start.

Updates and browser downloads

Windows setup supports signed automatic updates. Use Settings → Background behavior to check for updates; restart the app to apply a downloaded update. A newer setup can also update an existing installation.

Install the browser companion to send selected links and browser downloads to Fetchrail. For a paused or interrupted transfer, follow the resume guide.

Questions before installing

Is Fetchrail free?

Fetchrail is free to download and does not require an account. The source is available to inspect on GitHub; the repository does not currently provide an open-source license.

Does it always make downloads faster?

No. Parallel connections can help when a file server supports byte ranges and your connection has spare capacity. Your network and the server's limits still determine throughput.

Will uninstalling delete downloaded files?

Uninstall through Windows Settings → Apps → Installed apps. Downloaded files stay on disk; removing history and settings is optional.
