Fetchrail Browser Integration privacy policy

Last updated: 12 October 2026.

Fetchrail Browser Integration connects your browser to the Fetchrail download manager installed on your Windows or Linux computer. It processes the information needed to select, route and control downloads. The extension does not send this information to the developer, an analytics service or an advertising service.

Information processed

  • Downloads: file URLs, referring page URLs, filenames, file sizes, content types, progress and the transfer options you choose.
  • Page content: when you choose “This page” or a page batch, the extension reads relevant links, media URLs, labels and download controls on those pages.
  • Browsing activity: with optional website access, the extension temporarily observes HTTP(S) request URLs, request methods and tab identifiers to associate a file request with its download page, including redirects and popups. It does not sell or use browsing activity for advertising.
  • Authentication information: only when you explicitly enable “Use browser session for captured files”, the extension may capture the final request's Cookie, Authorization, Referer and User-Agent headers to let Fetchrail download a file using your existing website session.
  • Local preferences: routing choices, session support, queues, connection counts, speed limits, schedules and page-batch state.

Where information goes

The extension passes download requests and transfer controls to the local Fetchrail app through Chrome's native messaging API. Fetchrail contacts the file server you select to verify and download the file. When browser session support is enabled, the relevant session headers accompany that file request. File servers receive normal network-request information, including your IP address, and apply their own privacy policies.

The developer does not receive your download history, page content, browser session headers or local preferences. The extension contains no advertising, analytics or remotely hosted executable code.

Optional desktop performance calibration

The desktop app offers user-started hardware and connection tests with explicit network-data and temporary-disk budgets. Generated online traffic goes to Cloudflare's speed-test endpoints, which receive ordinary request information including your IP address. Downloaded files, browser credentials and measurement reports are not submitted. Measurements and hashed network, volume and host tuning keys stay in the private local performance.json file, bounded to four reports, 128 observations and 2 MiB. Tuning expires after 14 days or relevant engine, network or volume changes. You can reset this data or disable automatic tuning in Settings > Performance. No additional browser permissions are needed.

Storage and retention

Preferences and page-batch state are stored in local browser extension storage. Temporary request observations use browser session storage, are bounded in size and are ignored after two minutes. Disabling browser session support clears the captured request observations.

Fetchrail stores download history and unfinished-transfer details locally. If you enable session support, unfinished downloads may include sensitive session headers in the desktop app's local downloads.json file so they can resume after a restart. These headers are removed when the transfer completes or is removed. They are excluded from the extension's transfer status responses and the app's interface events. Downloaded files remain on your computer until you delete them.

Your choices

You can disable automatic download routing, leave browser session support off, revoke optional website access in your browser, stop a page batch, remove downloads from Fetchrail or uninstall the extension. Session support is off by default. Page scanning uses temporary access to the active tab after your action; broader HTTP(S) website access is optional and requested for page batches or session support. The extension does not capture private/incognito downloads.

Limited use

Fetchrail Browser Integration's use of information received from browser APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Information is used only to provide the extension's download-management features. It is not sold, used for advertising, used to determine creditworthiness or provided to data brokers.

Website and support

This policy describes the browser extension and its local desktop integration. The Fetchrail website is hosted by Cloudflare, which may process ordinary website request logs and aggregate website analytics. Those website visits do not transmit your extension download history or session headers. GitHub handles visits, software downloads and support issues under its own policies.

For questions or requests, email support.fetchrail@rrmtools.uk or contact the maintainer through GitHub. Do not include private download URLs, cookies or credentials in public issues.

Changes

This page will be updated when the extension's data handling changes. The date above identifies the current policy.
