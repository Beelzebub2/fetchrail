The engine

Split on the way down. Whole when it lands.

1 requestAsking the server
linux-desktop-24.04-amd64.iso
Saved · 4.2 GB
  1. 01

    Probe

    Before any bytes move, Fetchrail asks the server how long the file is and whether it honours byte ranges.

  2. 02

    Split

    The file is cut into segments that never overlap, one per connection. The count adapts to the file and the server, up to 32.

  3. 03

    Fetch

    Segments download side by side. If one drops, only that segment retries from its saved offset while the others keep going.

  4. 04

    Join

    Parts are merged into a temporary file and renamed only when every byte is present. A half-finished file never takes the final name.

Resume that checks before it trusts.

Pause
Closes the connections and frees the download slot.
Closed mid-transfer
The download comes back paused the next time Fetchrail starts.
Resume
Saved parts are reused only when the file's length, range layout and ETag or Last-Modified still match. Anything else restarts cleanly.
Pausedconnections closed · parts kept on disk
Resumedvalidators match · parts reused

If a server ignores byte ranges, Fetchrail drops the segmented attempt and fetches the file as a single stream instead.

  1. 01

    A download starts in your browser

    Click a file the way you always do. The companion notices it begin.

  2. 02

    The companion pauses it and asks Fetchrail

    Fetchrail makes its own request and compares the size and content type with what the browser saw.

  3. 03

    Fetchrail takes over

    The browser's copy is cancelled only after Fetchrail has accepted the file. If anything fails along the way, the browser carries on as if nothing happened.

And it does more than catch.

Picks from the page

Scan the current page for links and media, search and filter them, then send only the ones you want.

Works through download pages

For sites with countdowns, it opens each page in turn, follows a single clear download button and captures the final file. Logins and CAPTCHAs stay with you.

One right-click away

Choose Download with Fetchrail on any link, or control running transfers from the toolbar.
