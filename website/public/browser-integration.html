Connect your browser to Fetchrail

Send selected links and browser downloads to the Fetchrail desktop app on Windows or Linux. The companion can list files on the current page, send URL batches and control live transfers.

Install the desktop app first

Get Fetchrail for Windows or Fetchrail for Linux and launch it once to register the native messaging host. Open Settings → Browser for installation choices and the stable extension folders.

Chrome, Brave, Vivaldi and Chromium

Use the Chrome Web Store listing where supported. You can also enable Developer mode on your browser's extensions page, choose Load unpacked and select the Chromium folder shown by Fetchrail. Chrome 116 or newer supports automatic panel-aware companion reloads.

Firefox

Use a signed Mozilla Add-ons build when approved and available. The signed store build requires Firefox 140 or later. For temporary testing, open about:debugging#/runtime/this-firefox, choose Load Temporary Add-on and select manifest.json from Fetchrail's Firefox folder. A temporary add-on must be loaded again after a browser restart. Follow the maintained installation guide for current store availability.

Send a file to the app

  1. Right-click a link and choose Download with Fetchrail, paste URLs into the companion, or select links from This page.
  2. Choose the destination, queue, connection count or future start time.
  3. Use Send browser downloads to Fetchrail for automatic routing. The companion verifies the handoff before cancelling the browser's copy; a failed handoff continues in the browser.

Downloads that require a login

Use browser session for captured files is optional and off by default. When enabled, only the observed final GET's available Cookie, Referer, User-Agent and Authorization headers are forwarded to the local app. Unfinished transfers may store those headers locally for resume and scheduling; they are removed on completion or removal. Treat unfinished history as private. Read the privacy policy before enabling this option.

Limits and troubleshooting

Safari and mobile browsers require separate integrations. Native messaging depends on the browser's package and profile; Linux sandboxed browser packages may need additional setup. If the companion cannot connect, launch Fetchrail and check the native-host instructions in the companion guide. Protected-media capture is not a promised feature; use downloads the site makes available to you.

Transfers interrupted after handoff follow the same safe resume rules as pasted links.
